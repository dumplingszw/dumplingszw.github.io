最近在学 **LLM Agent** 开发，这里先记几个最基础、也最容易混淆的点。

## 什么是 Agent

简单说，Agent 就是「能自己决定下一步做什么」的程序：给定一个目标，它会循环地 **思考 → 调用工具 → 观察结果 → 再思考**，直到完成任务。

## 一个最小循环

```
目标 → LLM 决定动作 → 执行工具 → 拿到结果 → 反馈给 LLM → 重复
```

关键不在模型多强，而在 **工具（tool）和上下文（context）设计得合不合理**。

## 我在练的东西

- 用现成框架搭一个能调用命令行 / 搜索的 Agent
- 理解 system prompt 怎么写才不容易跑偏
- 看别人开源的 Agent 项目是怎么组织代码的
