我是怎么用 fork 学开源项目的

Jul 24, 2026

学编程这些年，我最受用的方法之一就是 fork 优秀开源项目。

为什么是 fork 而不是只看

  • fork 之后你能 直接改、直接跑，读不懂的地方加个 log 看运行结果
  • 可以在原项目基础上 做小实验，验证自己的理解
  • 顺手 star / 关注作者，慢慢就知道圈子里谁在认真做事

我的做法

  1. 找到感兴趣的项目，先读 README 和目录结构
  2. fork 到自己账号，git clone 下来跑通
  3. 挑一个功能点，试着改一改、断点跟一遍
  4. 把弄懂的东西写成笔记（也就是这个博客里的文章）

提醒

fork 是学习手段，不是终点。真要掌握，最后还是得 自己从零写点东西。
