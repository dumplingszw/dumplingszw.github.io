Function Calling 是怎么把“说话”变成“做事”的

LLM 只会“预测下一个 token”，它本身不能查天气、不能跑代码。把“说话”变成“做事”靠的是 Tool Calling（函数调用）。

流程大致是：

  1. 开发者把可用工具的描述（名字、参数、用途）随系统提示一起发给模型
  2. 模型输出一段结构化的调用请求（如 {"name":"get_weather","args":{"city":"上海"}}）
  3. 宿主程序真的去执行这个工具，拿到结果
  4. 结果再以消息形式喂回模型，模型据此继续

关键点：模型只负责“决定调哪个、传什么参”，真正执行的是你的代码。这也是为什么 Agent 工程里，工具的边界设计和错误处理比模型本身还重要。
